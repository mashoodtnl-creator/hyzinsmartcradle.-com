Smart features. Simple control.

ഒരു app-ൽ നിന്ന് rocking ആരംഭിക്കാനും timer, speed, lullaby എന്നിവ നിയന്ത്രിക്കാനും കഴിയുന്ന smart cradle system. Feature-കൾ മോഡലിനനുസരിച്ച് വ്യത്യാസപ്പെടാം.

01

One-tap rocking

App-ൽ start/stop control ഉപയോഗിച്ച് cradle rocking ആരംഭിക്കാനും നിർത്താനും.

02

Timer options

5, 10, 15, 20 മിനിറ്റ് പോലുള്ള timer preset-ുകൾ ഉപയോഗിച്ച് session നിയന്ത്രിക്കാം.

03

Rocking speed

അനുയോജ്യമായ rocking speed തിരഞ്ഞെടുക്കാൻ speed control option.

04

Lullaby & volume

Built-in audio module ഉപയോഗിച്ച് lullaby playback, volume control.

Component Breakdown • Layer 02

PCB-യിലെ ഓരോ ഭാഗവും എന്ത് ചെയ്യുന്നു?

Hardware-നെ ഓരോ component ആയി മനസ്സിലാക്കാം — control മുതൽ motor output, sound, power വരെ.

01

ESP32 NodeMCU — Main Controller

Cradle-ന്റെ പ്രധാന brain. Android app-ുമായി Wi‑Fi/Bluetooth communication, timer, speed commands, audio trigger, system logic എന്നിവ കൈകാര്യം ചെയ്യുന്നു.

Input: App commands / sensor data • Output: control signals
02

INMP441 — Digital Microphone

കുഞ്ഞിന്റെ ശബ്ദം കേൾക്കുന്നതിനുള്ള digital microphone module. Prototype-ൽ sound level/cry detection logic പരീക്ഷിക്കാൻ ഉപയോഗിക്കാം. Microphone മാത്രം sleep സ്ഥിരീകരിക്കില്ല.

Interface: I²S digital audio
03

BTS Motor Driver

ESP32-യുടെ ചെറിയ control signal ഉപയോഗിച്ച് 12V wiper motor-ന്റെ power നിയന്ത്രിക്കാൻ സഹായിക്കുന്ന motor driver stage. Motor current, heat, stall protection എന്നിവ design-ൽ പരിശോധിക്കണം.

Motor power path • PWM / direction control (driver-supported)
04

RTC Module

Real-time clock ഉപയോഗിച്ച് സമയം നിലനിർത്താം. Feeding reminder, diaper reminder, schedule എന്നിവയുടെ timing-ിന് ഉപയോഗിക്കാവുന്ന module.

Interface: I²C • Backup battery support
05

DY-SV5W + SD Card

SD card-ൽ സൂക്ഷിച്ച lullaby / audio files പ്ലേ ചെയ്യുന്നതിനുള്ള audio module. ESP32-യിൽ നിന്ന് trigger നൽകാം; speaker-ിലേക്ക് audio output എത്തിക്കും.

Audio playback • SD card file storage
06

Buck Converter — 12V to regulated voltage

Adapter-ൽ നിന്നുള്ള 12V supply-യെ ESP32, audio module തുടങ്ങിയവയ്ക്ക് ആവശ്യമായ regulated voltage-ിലേക്ക് കുറയ്ക്കുന്നു. Output voltage, current rating എന്നിവ board design അനുസരിച്ച് ഉറപ്പാക്കണം.

12V input • regulated DC output
07

4W Speaker

DY-SV5W audio output-ിൽ നിന്ന് lullaby, recorded voice prompts തുടങ്ങിയ ശബ്ദങ്ങൾ കേൾക്കാൻ. Speaker-ന്റെ impedance, module output rating match ചെയ്യണം.

Audio output • 4W speaker (matching impedance required)
08

12V Wiper Motor

Cradle-ന്റെ rocking mechanism-ന് mechanical movement നൽകുന്ന motor. Motor mount, linkage, stroke, rocking angle, speed limits എന്നിവ prototype test-ൽ tune ചെയ്യേണ്ടതാണ്.

12V DC motor • mechanical motion output
09

12V / 5A Adapter

System-ന്റെ DC power source. Motor-ന്റെ startup/stall current, audio, electronics load എന്നിവ കണക്കാക്കി supply, fuse, wire gauge, connector എന്നിവ തിരഞ്ഞെടുക്കണം.

External power • overload protection recommended
Safety note: ഇത് prototype / product concept വിശദീകരണമാണ്. Cradle-ന്റെ mechanical stability, motor runaway prevention, emergency stop, pinch-point protection, safe sleeping surface, current/temperature protection, fail-safe stop എന്നിവ engineering test ചെയ്ത് ഉറപ്പാക്കിയ ശേഷമേ baby-use product ആയി ഉപയോഗിക്കാവൂ. Sound-based sleep detection ഒരു ഉറപ്പായ sleep monitor അല്ല.
